# om-sdlc-sandbox

A process sandbox for the Open Mercato (OM) agent skills: the pipeline configuration that drives them and the design documents for the team's software delivery process. There is no application code yet.

## Contributing

Work is issue-first. Before you file an issue, find the route it will take:

- [Routes](SDLC.md#routes): what happens to each category of issue, from intake to merge.
- [Categories](SDLC.md#categories): which category label fits your issue.

The full process is in [`SDLC.md`](SDLC.md).
